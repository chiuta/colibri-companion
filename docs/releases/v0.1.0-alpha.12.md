# Colibri Companion v0.1.0-alpha.12

Early alpha. Everything below was checked by automated tests and by drawing the window without a screen; **nothing was run against a real model, a graphics card, or real IQ4/BERT files.**

**Please use alpha.12.** The files published as alpha.9 were built from the alpha.8 code, and the files published as alpha.11 were built from the alpha.10 code (they report themselves as alpha.10, so the update check keeps offering an update). Neither contains anything that is not in alpha.8 or alpha.10.

## New in the window
- **Research tools** (Documents window): search with real PDF/EPUB page numbers, citation check with pages, provenance receipts (optional key) and their verification, an AI-use declaration in 8 languages, and a retrieval-quality measure.
- **Second reading of citations by the model** (button, Stop, at most 40 calls). It can be wrong.
- **Bibliography and citations**: find and merge duplicates, check DOI/ISBN/ISSN/ORCID, write `[@key]` citations in APA, author-year or numeric style, save .bib/.ris/.json files.
- **Search by meaning** in the window, if you start an embeddings server yourself (for example `corbul serve --encoder`). Tested only with a stand-in server and synthetic vectors.
- **Chicago and Vancouver** citation and export styles, next to APA, Harvard and IEEE.
- Per-collection "shelves" are built in the background when you add files.

## New in the corbul engine (separate program)
- 16 quantisation types, including IQ4 (not yet compared against real llama.cpp files).
- WordPiece tokenizer and BERT-style encoders; `corbul embed`, `corbul rerank` and `serve --encoder`.
- Still unsupported: IQ1–IQ3, RoBERTa/XLM-R, RWKV GGUF, Zamba.

## Fixes
- The embeddings key is never sent in clear text (`http://`) to a computer outside your own network; a vector larger than any real model produces, or an `index` that is not a position, is refused.
- A poisoned lock can no longer bring the window down (the two places that read the connection settings).
- Version comparison is covered by tests (`alpha.10` is newer than `alpha.9`, junk tags are never newer).
- New tests with hostile input: the search-by-meaning shelf (NaN, infinite, huge and empty vectors), all five citation styles on garbage entries, and many kinds of malformed embeddings answers.
- New `docs/RELEASING.md` in 8 languages: how a release is made, and never to change the tag name in the draft.
- Search by meaning: a result for one collection can no longer be written into another one, and it is used only with the model the shelf was prepared with (otherwise the window says so and searches by words).
- Chicago style: an entry with no year no longer shows a doubled full stop.
- The release workflow now refuses a version tag that already points at another commit.
- Saved speed profiles (autotune): on Windows two saves at the same moment could, rarely, skip the file lock and lose one update; it now retries briefly instead.
- Tests: the embeddings test server and one slow-frame limit were made reliable on Windows and macOS Intel.
- A Windows server bug: replies sent right before a connection closed could be lost; the server now closes gracefully.
- CI: new clippy lints, three platform-dependent tests (Windows, macOS Intel and ARM), and the `url` security advisory RUSTSEC-2026-0592.

## Known limits
Search by meaning needs an embeddings server you start yourself and has not been tried with a real model. No GPU backend in corbul has run on real hardware. Windows and macOS builds are automatic and little tested.
