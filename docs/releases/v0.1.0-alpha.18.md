# Colibri Companion v0.1.0-alpha.18

Early alpha. Checked by automated tests and CI builds; **nothing was run against a real model, a graphics card, or the window on a real screen.**

**Please use alpha.18** (it includes everything in alpha.17).

## Fix
- **A model path that was refused with “config.json is missing”.** *Use this model* took anything that was not a file for a colibri model folder. Now the path is cleaned first (quotes and the invisible direction marks Windows adds when a path is copied from a file's properties), a name typed without `.gguf` is tried with it, and a folder that holds a `.gguf` file (also one level down) leads to that file. A folder with several models lists them, and a path that does not exist or a folder with no model says so, instead of asking for `config.json`.
