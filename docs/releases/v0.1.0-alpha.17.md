# Colibri Companion v0.1.0-alpha.17

Early alpha. Everything below was checked by automated tests (and CI builds); **nothing was run against a real model, a graphics card, or the window on a real screen.** All the new cache features were tested on tiny random models only: they show the code is correct, not that it is fast or accurate on real models.

**Please use alpha.17** (it includes everything in alpha.16). Delete the mislabeled or empty releases: alpha.9, alpha.11, `alpha13` (no dot) and alpha.14.

## New since alpha.16
- **Shrunk context packs**: when the documents do not fit the model's window, corbul can keep only the rows that matter most (`corbul packs --shrink auto|R`, the `shrink` field of `/v1/packs/complete`, and *Documents → Context packs → Shrink texts that are too long*). Information is lost; measure how much with *Measure cache shrinking…*. See `docs/SHRINK-MAP.md` (8 languages).
- **Cache maps between models** (`corbul map-fit`, `corbul map-check`): learn a map from one model's cache rows to another's (same tokenizer needed) and measure what it does to the answer. Command line and library only for now; whether it pays off must be measured on a real pair of models.
- **Packs on the shelf** can be kept at half the size (F16) and compressed; `corbul kvfit` measures what shrinking the cache and refitting values costs, with a window in Companion.
- CartaColibri: `--packs-shrink`.
